# issue #128-1 · 页面之间跳转时的水平位移（原始输出）

方法：真实 Chromium（1280×800，保留经典滚动条），从首页出发，用页头的导航依次点击
标签 → 归档 → 百宝箱 → 帮助 → 标签 → 首页 → 百宝箱 → 首页，每到一页读取页头各元素的水平位置（px）。
「滚动条占位」是 `window.innerWidth − documentElement.clientWidth`；改动后一屏放得下的页面没有滚动条，
这一列是 0，但布局宽度已经按预留后的宽度计算（后面几列与有滚动条的页面完全相同）。
